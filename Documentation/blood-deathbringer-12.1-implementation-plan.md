## 目标

模块最终需要实现以下目标：

1. 紧急治疗优先保证生存，不因输出循环抢占灵界打击资源。
2. 在单体、双目标和群怪之间使用可解释的资源循环。
3. 将死亡使者的核心技能窗口与血债、沸点、赤色天灾和死神印记等状态关联。
4. 防御技能按照伤害类型、目标数量、血量和技能时间轴判断，而不是只按单一血量阈值判断。
5. 对自动化无法可靠判断的技能保留手动控制，避免误放关键技能。
6. 所有新增状态都有明确生产者、消费者、测试和回滚边界。

### 已实现技能优先级

模块不是把所有技能按固定技能表平铺，而是按 `Rules` 数组从上到下判断；`Condition == "false"` 的兼容占位不参与执行。当前有效顺序和关键数值如下：

```text
1. 心灵冰冻：目标或焦点可打断读条剩余 `<=5` 秒，且对应距离 `<=15` 码。
2. 加血灵界打击：生命值 `<=35` 且符文能量 `>=40`；或生命值 `<=50` 且符文能量 `>=80`；或生命值 `<=60` 且符文能量 `>=40`。
3. 治疗石 / 浓缩银月城生命药水：生命值 `<=35`，治疗石优先；浓缩药水使用 `271884/271885` 的 `/use` 宏，普通药水回退使用 `241304/241305` 的 `/use` 宏；灵界打击确认失败后立即让出给紧急物品。
4. 吸血鬼之血 / 冰封之韧：分别在生命值 `<=25%` / `<=20%` 时使用，且仅在 `首领战 == 0` 时自动释放。
5. 骨盾保鲜与抢救：白骨之盾剩余 `<=5` 秒用死神的抚摩续上；10 层血债时，骨盾 `<7` 层优先使用普通 2 符文精髓分裂；若同时有破灭且剩余 `<=3` 秒，则在骨盾未满 12 层时优先使用破灭触发的 1 符文精髓分裂；无条件高骨盾精分停用，避免低效率重复消耗符文。
6. 符文刃舞：爆发开关开启、有效敌对目标在 5 码内且技能可用时立即释放；只有收到符文刃舞成功事件后才打开 3 秒 `符文刃舞爆发窗口`，亡者复生和巫妖之躯在该窗口内对齐释放，不依赖滞后的实际光环。
7. 死神印记：普通、精英和首领目标均可在骨盾低于 8 层、符文能量 `<80`、距离 `<=5` 码且技能可用时补盾；副本外独立分支允许所有有效目标，副本内独立分支仍只允许目标类型 `>90`，高能量时让位给灵界打击。
8. 高亮血液沸腾：`血沸手动触发 == true` 只表示当前高亮链的第一次待按键触发；成功确认后切换为 `血沸自动链 == true`，后续高亮血沸由游戏自动释放，不重复发送按键。
9. 枯萎凋零：战斗时间 `<15` 秒时移动为假且站定 `>=1` 秒；达到 `>=15` 秒后仍要求非移动且血色之地消失才补铺。
10. 午夜舞步心脏打击、破灭精髓分裂：按目标、距离、资源和对应高亮条件执行。
11. 泄能灵界打击：生命值 `>60` 且符文能量 `>=80`。
12. 普通血沸：生命值高于 40%、无高亮且血沸充能达到 2 层时手动使用；不受符文数量和符文能量阈值限制，也不再与心脏打击次数组成循环。
13. 普通心打：无午夜舞步高亮、有符文且未到泄能线时使用；高亮心打和普通心打互斥但互不计数。
14. 死神脚步、反魔法护罩：保持手动；无可执行动作时暂停。

`血沸手动触发` / `血沸自动链` 现在按 SeUI 的事件模型维护：`SPELL_ACTIVATION_OVERLAY_GLOW_SHOW/HIDE` 识别高亮边沿，第一次高亮进入待按键阶段；`UNIT_SPELLCAST_SUCCEEDED` 确认第一次血沸后切换到自动链阶段，连续高亮期间不会再次产生手动按键。`1265968` 与 `1265982` 的沸点光环作为高亮 API 不可用时的回退和诊断来源；覆盖技能 ID 也通过基础/当前技能 ID 识别。脱战和切换专精仍会清理该状态。
```

## 单一事实来源和同步顺序

```text

  -> 应用构建和模块打包
```
